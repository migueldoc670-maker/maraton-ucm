# Maratón UCM

Guía cronológica del Universo Cinematográfico de Marvel con casillas para marcar lo que has visto.

- 60 títulos en orden cronológico (películas, series y especiales).
- Emblemas animados originales, filtros, buscador, progreso por saga y confeti al completar.
- El progreso se guarda en tu navegador; puedes exportarlo e importarlo.
- Guía de fans no oficial. Sin imágenes ni logotipos oficiales.

Es una sola página estática (`index.html`), sin dependencias.
